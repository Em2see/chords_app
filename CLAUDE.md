# Chord Trainer — тренажёр аккордов для фортепиано

## Суть проекта
Веб-приложение для тренировки трезвучий, септаккордов и слэш-аккордов на фортепиано.
Генерирует последовательности (круг квинт/кварт, ii–V–I, диатоника, хроматика, случайно),
показывает всю цепочку или только следующий аккорд, подсказывает обращение
с минимальным движением голосов. Основное устройство — планшет на пюпитре.

## Стек
- TypeScript (strict), Vite 6
- UI: без фреймворка; тяжёлые зависимости не тянуть
- Звук: Web Audio API, без библиотек
- Тесты: Vitest (логика), Playwright (e2e и визуальные), Lighthouse CI (загрузка)
- Хранение настроек и прогресса: localStorage, всегда в try/catch
- Сборка и запуск — только внутри Docker; npm на хосте не запускать

## Музыкальные правила (критично)
- Нота хранится как { letter: NoteLetter, alt: Alteration }, MIDI-номер — производный.
- Написание должно быть теоретически верным: в F# мажоре A#, в Gb — Cb,
  Cdim7 = C–Eb–Gb–Bbb. Двойные знаки допустимы.
- Энгармонический шов круга (F#/Gb) — настраиваемый (Settings.seam).
- Типы аккордов: maj, min, dim, aug, sus2, sus4, maj7, 7, m7, m7b5, dim7.
- Трезвучие имеет 3 положения, четырёхзвучный аккорд — 4.
- Ведение голосов (правая рука, тесное расположение):
  - выбирать положение с минимальной суммой |сдвигов| голосов в полутонах;
  - при равенстве — больше общих звуков;
  - диапазон правой руки F3–G5 (MIDI 53–79), настраиваемо;
    при выходе за границы — перенос на октаву.
- Левая рука: основной тон или бас слэш-аккорда, диапазон C2–B3 (MIDI 36–59).
- Слэш-аккорды классифицируются:
  1. бас — звук аккорда → обращение (C/E, C/G);
  2. бас достраивает септаккорд (C/B = Cmaj7, C/Bb = C7/Bb);
  3. бас вне аккорда (C/D, C/F) → «трезвучие + чужой бас».

## Настройки (Settings)
- progressionMode: fifths | fourths | ii-V-I | diatonic | chromatic-up | chromatic-down | random
- chordType, keyRootPc (0–11), seam (sharp|flat)
- hintLevel: 1 (сразу) | 2 (задержка) | 3 (по кнопке H)
- inversionMode: all | root | first | second | non-root
- accidentalFilter: both | no-flats | no-sharps | naturals
- bpm (40–200), beatsPerChord (1|2|4), autoAdvance, playSound
- Ключ localStorage: chord-trainer-v1

## Метроном
- Класс Metronome в src/audio/metronome.ts
- Планирует клики через AudioContext.currentTime с упреждением LOOKAHEAD_S=0.1 с,
  поллинг TICK_MS=25 мс
- Визуальные колбэки (onBeat, onAdvance) через setTimeout с рассчитанной задержкой
- Акцент (даунбит): 1500 Гц, 0.35 gain; не-акцент: 900 Гц, 0.15 gain
- metro.bpm и metro.beatsPerChord можно менять на лету (без перезапуска)
- Enter — старт/стоп

## Аудио синтез
- playChord(midis, opts) — triangle wave, 6 мс атака, exponential decay 2 с
- Уровень: opts.volume / √N (equal-power mix)
- midiToFreq(midi) = 440 × 2^((midi−69)/12)

## Уровни подсказок
1. Нужное положение показано сразу, со стрелками движения голосов.
2. Подсказка появляется с задержкой N секунд (настраиваемо).
3. Подсказки нет, только по кнопке H.

## Нотный стан (этап 12)

### Модуль `src/ui/staff.ts`
- Экспортирует `renderStaff(voicing: Voicing, chord: Chord): string` → SVG
- Два стана в одном SVG: treble (скрипичный) сверху, bass (басовый) снизу, соединены акколадой
- Без внешних зависимостей; abcjs не тянуть

### Позиционирование нот
Позиция ноты на стане — дискретный шаг вдоль линий и промежутков.
`position = (octave − refOctave) × 7 + letterStep − refStep`
где `letterStep`: C=0 D=1 E=2 F=3 G=4 A=5 B=6

| Стан         | Нижняя линия | refOctave | refStep |
|--------------|-------------|-----------|---------|
| Скрипичный   | E4          | 4         | 2 (E)   |
| Басовый      | G2          | 2         | 4 (G)   |

Y-координата: `y = staffBottom − position × halfStep`, где halfStep = 4px.

### Знаки альтерации
Берём из `chord.notes[i].alt` (−2..+2) — не пересчитываем из MIDI.
Символы: −2=𝄫 −1=♭ 0=(показываем ♮ только если нота была изменена в предыдущем такте) +1=♯ +2=𝄪.
Для тренажёра: рисовать ♭ и ♯ всегда когда alt≠0, ♮ не рисовать (нет концепции такта).

### Добавочные линейки
Для каждой пропущенной позиции вне стана (position < 0 или > 8) рисовать горизонтальную черту
шириной ±9px от центра головки.

### SVG-параметры
- viewBox: `0 0 200 120` (два стана + зазор)
- Расстояние между линиями: 8px → высота стана 32px
- Головка: `<ellipse rx="5" ry="4" transform="rotate(-20)"/>`
- Штиль: линия длиной 30px, вверх если position < 4 (серединная линия стана), вниз иначе

### Настройка
`Settings.showStaff: boolean` (default false).
В tablet landscape стан размещается в левой колонке под цепочкой.
На малых экранах — под клавиатурой.

## Распознавание через микрофон (упрощённое)
- Web Audio API: AnalyserNode + ScriptProcessor/AudioWorklet
- Алгоритм определения высоты: autocorrelation (YIN lite) — достаточно для одиночных нот
- Распознаём отдельные ноты последовательно (не аккорд целиком): сыграл ноту → совпала?
- Порог громкости: не реагировать на тишину (RMS < порога)
- Режим «контроль»: пользователь играет ноты аккорда поочерёдно, приложение подтверждает
- Не требовать точного совпадения одновременно всех голосов — только нахождение ноты в аккорде
- Latency: AudioWorklet предпочтительнее ScriptProcessor (deprecated в Chrome)

## MIDI-вход
- Web MIDI API: navigator.requestMIDIAccess()
- Слушать noteOn (status 0x90) с velocity > 0
- Сопоставлять сыгранные ноты с curV.right + curV.left
- Два режима проверки: «любая нота аккорда» (мягкий) и «все ноты» (строгий)
- Fallback: если Web MIDI недоступен (iOS Safari), предложить микрофон или ручное подтверждение
- Визуально: подсвечивать сыгранные клавиши другим цветом до совпадения
