## Этап 12. Нотный стан

### Цель
Показывать текущий аккорд в нотной записи: скрипичный ключ (правая рука) + басовый ключ (левая рука).
Включается через настройку — планшеты с большим экраном могут показывать одновременно клавиатуру и ноты.

### Задачи
- [ ] Новый файл `src/ui/staff.ts` — чистая SVG-функция без DOM и аудио
  - `renderStaff(voicing: Voicing, chord: Chord): string` → SVG-строка
  - Два стана: treble (скрипичный) + bass (басовый), соединённые акколадой
  - Нотные головки для каждой ноты из voicing.right (treble) и voicing.left (bass)
  - Добавочные линейки (ledger lines) выше/ниже стана
  - Знаки альтерации: ♯ ♭ ♮ 𝄪 𝄫 — берём из chord.notes[i].alt, не пересчитываем
  - Ключевые знаки: рисовать только альтерации, характерные для тональности (опционально)
- [ ] Позиционирование нот на стане:
  - Позиция = (октава − ref_octave) × 7 + letterStep − ref_step
  - Скрипичный: нижняя линия = E4 (MIDI 64), шаг = E
  - Басовый: нижняя линия = G2 (MIDI 43), шаг = G
  - letterStep: C=0 D=1 E=2 F=3 G=4 A=5 B=6
- [ ] Добавить в Settings: `showStaff: boolean` (default: false)
- [ ] Обновить `buildSettingsBody()` — галочка «Нотный стан»
- [ ] Добавить `<div id="staff" class="staff-wrap"></div>` в scaffold, скрыт если !showStaff
- [ ] Обновить `render()` → вызывать `renderStaff()` при showStaff=true
- [ ] CSS: `.staff-wrap svg` — адаптивная ширина; в tablet landscape — в левой колонке под цепочкой
- [ ] Юнит-тесты в `tests/unit/staff.test.ts`:
  - Нота C4 (treble) получает корректную позицию Y
  - Нота с ♭ получает знак альтерации перед головкой
  - Добавочные линейки генерируются для C4 (ниже стана скрипичного) и C6 (выше)
  - Все 11 типов аккордов во всех 12 тональностях — нет исключений при рендере

### Технические детали
- Только SVG, без внешних библиотек (abcjs не тянуть)
- SVG viewBox: ~240×120 (два стана по 40px высотой, зазор 20px, отступы)
- Расстояние между линиями стана: 8px → полная высота стана = 32px (4 интервала)
- Головка ноты: эллипс rx=5 ry=4, наклонена (-20°)
- Штиль: вертикальная линия от головки, вверх для нижних нот, вниз для верхних
- Знаки альтерации рисовать слева от головки (–12px offset), уменьшенным шрифтом
- Добавочная линейка: горизонтальная черта шире головки (±9px) на каждой пропущенной позиции
